# cursor-slack-starter

Cursor Cloud Agent と Slack の連携を確認するためのスターターリポジトリです。

## 担当の分け方

- **技術作業**（調査・実装・テスト・PR）→ Cursor / Cloud Agents
- **受付・判断・振り分け** → mari
- **運用・定期・常駐** → Grok Bot（実装が必要なら Cloud Agents へ委任）

## 置き場

- **Obsidian** … 記録
- **Notion** … 成果物
- **Slack** … 連絡共有
